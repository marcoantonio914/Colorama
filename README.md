# Controle de níveis de água – Utilização biblioteca Colorama
Este projeto em Python foi criado para praticar o ciclo ** Bibliotecas**.
O programa solicita simula o monitoramento de um reservatório de água com as seguintes regras:
1. **Nível 1:** - Muito baixo (crítico) - ![Vermelho](https://img.shields.io/badge/Vermelho-red) 
2. **Nível 2:** - Baixo - ![Amarelo](https://img.shields.io/badge/Amarelo-yellow) 
3. **Nível 3:** - Médio - ![Verde](https://img.shields.io/badge/Verde-green) 
4. **Nível 4:** - Alto - ![Ciano](https://img.shields.io/badge/Ciano-cyan) 
5. **Nível 5:** - Muito alto (alerta) - ![Azul](https://img.shields.io/badge/Azul-blue) 

## Para esse projeto utilizei duas soluções.

A primeira (que se encontra no arquivo projeto.py), cria uma função para associar o número do nível à sua situação + cor correspondente

A segunda (que se encontra no arquivo projeto_dict.py), utiliza a função dict que cria uma biblioteca, mapeando o nível à situação.
Embora a função dict não tenho sido alvo do estudo em questão, entendi que visualmente, a interpretação fica mais clara utilizando a biblioteca dict, mas é apenas mais uma forma de chegar no mesmo resultado, e aproveitando os recursos nativos em Python.
